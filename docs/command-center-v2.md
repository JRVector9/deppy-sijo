# Command Center v2 개발 브랜치

`feat/agent-command-center-v2-20261020`는 승인한 1안 발전형을 구현한 격리된 개발 브랜치다. 기존 앱의 기본 화면과 metadata DB를 유지한다. 제품 릴리스·실행 앱 교체는 이 작업에 포함하지 않는다.

## 화면과 작업 흐름

1. 왼쪽에서 기존 워크스페이스를 선택한다. 프로젝트를 선택하면 그 프로젝트의 메인 화면을 연다. 세션은 각자 실제 터미널로 연결된다.
2. **프로젝트 설정**에서 메인 agent/model/effort, 허용 작업자, 작업 범위, 동시 실행 수, 배정 전 확인·독립 worktree 정책을 저장한다. 저장된 설정 revision은 새 실행에 적용한다.
3. 메인 세션을 생성하거나 정확한 기존 세션을 연결하고 목표를 보낸다. Codex의 지원되는 구조화 응답은 검증된 계획 제안으로 연결한다. 다른 CLI의 대화는 기존 터미널로 유지하며 수동 계획·결과 보고를 사용한다.
4. 계획의 작업 범위·담당·실행 기기·완료 조건을 검토하고 확인한다. 실제 허용된 작업만 독립 세션에 배정한다. 같은 문장을 새로 보내도 별도 입력으로 취급한다.
5. 오른쪽 작업자 모니터에서 선택 프로젝트의 진행·승인·결과를 확인한다. 세부 화면은 정확한 task/attempt의 터미널·Git·기록을 연다. 입력 접수, 실행 관측, 결과 제출, 검증, 최종 확인은 별도 상태다.
6. **워커 종료**는 이 화면이 생성하고 여전히 소유한 정확한 실행만 종료한다. 이미 실행된 작업의 결과나 검증 판정은 바꾸지 않는다. 수동 연결 세션은 기존 터미널의 종료 기능을 사용한다.

## 다른 컴퓨터 연결

- 실행 서버의 TLS listener와 **이 컴퓨터에서 프로젝트 실행 허용**은 별도다. 서버에서 로컬 프로젝트·controller의 프로젝트 ID·폴더·허용 agent를 확인하고 실행을 명시 허용한다.
- 현재 TLS listener는 loopback 전용이다. 다른 컴퓨터에서는 보안 터널/포트 전달을 준비한 뒤 그 endpoint를 사용한다. 자동 LAN 검색·직접 공개 listener는 제공하지 않는다.
- controller의 기기 화면에서 endpoint·인증서 fingerprint·프로젝트 전용 token을 입력한다. 실제 설치 agent/profile·폴더·용량을 조회한 뒤 명시 허용한다.
- token은 정확한 device/workspace/grant에 제한된다. UI snapshot이나 SQLite에는 원문을 저장하지 않는다. 실행 권한을 회수하면 기존 scoped 연결과 대기 중 실행도 무효화한다.
- 원격 터미널 화면·native 후속 입력·정확한 실행 종료를 제공한다. 연결 유실만으로 다른 기기에서 같은 작업을 다시 실행하지 않는다.

## 응답 유실과 복구

**원래 요청 상태만 확인**은 현재 연결에 보존된 원래 launch/input operation을 읽기 전용으로 조회한다. 새로운 작업자나 입력을 보내지 않는다. 생성만 확인된 워커는 `작업 지시 미전달`로 표시하며 자동 지시를 재개하지 않는다. 필요하면 정확한 실행을 명시 종료한다.

원래 입력의 접수가 확인되면 당시의 sequence/time을 사용한다. 새로 조회한 시간이나 다른 입력의 sequence를 성공 근거로 대체하지 않는다. 재시작 뒤 immutable 원요청·임대가 없으면 `관측 불명`을 유지한다.

## 모바일과 기존 화면

PWA와 Relay는 같은 project/task/attempt를 표시한다. 읽기·입력·승인은 기존 연결 권한으로 다시 검사한다. 원격 워커 화면은 PWA에서 읽기 전용이며 cross-TLS cloud 입력은 비활성화한다. native 원격 입력과 구분한다. 원격 화면은 보이는 동안만 bounded watch를 갱신하고 내부 스크롤과 읽던 위치를 보존한다.

새 화면은 `DEPPY_COMMAND_CENTER_V2=1`로 시작한 빌드에서만 사용할 수 있다. 상단 **기존 화면**으로 돌아가도 진행 중 세션은 유지된다. 기본값은 기존 화면이다. 이 문서의 opt-in 안내는 앱 실행·재시작 명령이 아니다.

원본 source 복구는 [복구 문서](command-center-rollback.md), 검사 범위와 미실행 항목은 [검증 기록](qa/2026-10-20-command-center-v2-implementation.md)을 참고한다.
