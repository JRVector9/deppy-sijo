UX 계약

‘주소 준비됨’은 에이전트 연결 성공을 뜻하지 않습니다. ‘인증 대기’와 ‘도구 호출 확인’을 구분하고, 만료된 인증에는 입력 권한 조작을 막습니다. 조회를 끄면 입력도 꺼지고, 취소 요청은 작업의 실제 종료와 구분합니다. 연결 해제 후에도 저장한 답변은 남습니다.

좁은 설정 창에서는 목록 아래로 선택 상세가 내려갑니다. 헤더와 탭은 고정되고 본문만 스크롤합니다. 권한 표는 열을 겹치거나 글씨를 줄이지 않고 필요할 때 내부 가로 스크롤을 사용합니다. 색상 외에도 상태 문구를 항상 제공합니다.

구현 범위

이번 결과물은 HTML 설계 시안입니다. 기존 기능을 재배치한 부분은 인증·개별 토큰·세션 접근권·입력 회수·작업·수신증·프로필·재연결입니다. 목록·상세 구조, 4개 탭, 일관된 행과 빈 상태는 적용할 UI 변경입니다. 제공자별 실제 호환성을 보장하는 새 상태나 자동 권한 승인 기능은 추가하지 않습니다.

고급 설정의 공용 토큰·종료된 세션·지시문은 삭제하지 않고 접어 둡니다. 제품 구현 시 공용 SettingsDetailShell·SettingsRow와 현재 cloud controller의 ID 기반 동작을 재사용합니다.
