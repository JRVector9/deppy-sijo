요청한 변경 확인

상단 제목 제거: 실제 메뉴에 ‘정리안’ 등의 제목을 넣지 않습니다. 가로는 대부분 202pt, 가장 긴 환경·API 메뉴는 220.3pt로 두 시안보다 작습니다.

세로 간격: 바깥 여백 4pt, 행 사이 pt입니다. 한 행은 18pt이며 메뉴 안에서 줄바꿈하지 않습니다. 긴 글자는 필요한 만큼 너비를 늘립니다.

추가 수정: 파일 목록 헤더의 우클릭이 열리지 않는 결함을 발견해 수정했습니다. 실제 우클릭 후 ‘새 폴더’ 표시와 ‘메모’ 탭의 왼쪽 클릭을 회귀 테스트로 확인했습니다.

시안과 남아 있는 외형 차이

배경·테두리: HTML은 #21252d / #414956, 앱은 기존 공통 테마의 #181b20 / #32363e를 사용합니다.

모서리·글자: HTML은 모서리 5px / 글자 12px, 앱은 1pt / 13pt입니다. 아이콘도 HTML 15px, 앱 14pt의 벡터 그림으로 약간 다릅니다.

메뉴 구성과 축소는 적용됐지만 외형이 픽셀 단위로 같지는 않습니다. 오른쪽 이미지에서 차이를 그대로 확인할 수 있습니다.

측정 방법·소스·검증 범위 보기

실제 production 메뉴 함수를 egui_kittest에서 우클릭/hover로 열었습니다. Popup Area의 경계와 접근성 버튼 경계를 측정하고, 같은 화면을 PNG로 렌더링했습니다.

최초 시안 원본은 이전 수정 때 덮어써져 기록된 284px / 32px / 여백 5px로 복원했습니다. 제목의 정확한 원래 높이는 남아 있지 않아 최초 시안의 총 높이 감소율은 주장하지 않습니다. 지난 수정 시안은 기존 HTML의 256px / 28px / 여백 4px CSS를 사용합니다.

한국어 기본 글꼴·다크 테마의 대표 상태를 검증했습니다. 임의 글꼴/배율, 모든 조건별 분기, 실행 중 앱의 픽셀 일치까지 검증한 것은 아닙니다. 실제 세션 입력·파일 삭제는 실행하지 않았습니다.
