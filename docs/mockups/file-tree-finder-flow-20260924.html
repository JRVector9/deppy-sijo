프로젝트 파일 검색

현재 프로젝트의 파일명과 상대 경로를 찾아 트리 위치로 이동합니다.

Enter로 첫 결과를 열고, Esc로 검색을 닫습니다. 결과에는 부모 경로를 함께 표시합니다.

새 파일 만들기

좁은 트리 행 대신 넓은 대화상자에서 이름과 위치를 확인합니다.

Enter로 만들기 · 같은 이름이 있으면 덮어쓰지 않고 알려줍니다.
