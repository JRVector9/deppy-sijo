새 작업 설명이 들어오면 카드의 두 줄 내용이 갱신됩니다.

카드의 ⋯ 또는 ‘예약’을 누르면 해당 세션의 창이 가운데 열립니다. 제목을 끌어 이동하거나 오른쪽 아래를 끌어 크기를 바꿔 보세요. 창을 다시 열면 중앙에 놓이고, 조절한 크기는 같은 종류의 창에서 유지됩니다. 브로드캐스트는680×560 고정 창에서 본문만 스크롤합니다.

기존 공용 스타일에 크기 조절을 더합니다

최초 표시와 다시 열 때는 앱 전체 화면 중앙입니다. 열린 뒤에는 제목을 끌어 옮기고, 모서리를 끌어 크기를 조절합니다. 입력창도 함께 커지며 제목과 하단 버튼은 고정되고 본문만 스크롤됩니다.

작업 설명을 유지하는 규칙

현재 사용자 지시 → 현재 요약 → 같은 실행·세션의 마지막 작업 순으로 표시합니다. 새 데이터가 비어도 기존 내용은 지우지 않습니다. 이전 내용을 쓰면 ‘최근 작업’, 종료된 세션은 ‘마지막 작업’으로 구분합니다. 다른 세션·새 에이전트의 내용을 가져오지 않습니다.
