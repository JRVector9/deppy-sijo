연결된 세션 선택

Mac 연결 상태와 워크스페이스를 확인하고, 작업 중인 세션을 선택합니다. 기존 Deppy 모바일 목록의 세션 진입 흐름을 유지합니다.

  1. 연결된 Mac 이름과 상태를 먼저 확인합니다.
  2. 세션 행을 누르면 해당 터미널로 들어갑니다.
  3. 터미널 상단 제목에서 다른 세션으로 이동합니다.

시안에서 확인할 결정

deppy-mux의 하단 도크 구성과 연결 복구 표현을 참고했습니다. Deppy의 현재 원격 터미널 캔버스와 전송 경로를 전제로 한 화면 제안입니다.

입력창 초안은 세션별로 유지하고, 전송 중·거절·연결 끊김 상태는 하단 입력 영역 안에 표시합니다. 이 HTML은 실제 Mac이나 터미널에 연결하지 않습니다.

화면의 전송·연결 버튼은 시나리오 확인용 시뮬레이션입니다.
