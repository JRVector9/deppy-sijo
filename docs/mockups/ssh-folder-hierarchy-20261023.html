바뀌는 부분

  1. 상위 > 하위 경로현재 위치를 경로 막대로 보여줍니다. 상위 경로를 누르거나 위쪽 화살표로 돌아갈 수 있습니다.
  2. 접고 펼치는 폴더들여쓰기와 폴더 아이콘으로 관계를 구분합니다. 펼쳐도 선택한 폴더는 바뀌지 않습니다.
  3. 짧고 고정된 목록폴더가 많으면 목록 안에서 스크롤합니다. 선택 경로와 추가 버튼은 밀려나지 않습니다.
  4. 선택 대상을 명확하게선택 행에 청록색 표시를 붙이고, 하단에 전체 경로를 보여줍니다.
