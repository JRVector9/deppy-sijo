Finder는 폴더를 고를 때만 열립니다.
내 폴더

기존 동작을 유지합니다. 출처를 선택한 다음에만 Finder를 엽니다.

Git URL

HTTPS 또는 git@host 형태의 URL을 복제한 뒤, 로컬 폴더를 워크스페이스로 등록합니다.

SSH 주소

원격 호스트와 작업 폴더를 지정합니다. 별도 원격 워크스페이스이며 파일 트리와 세션 재접속은 구현 범위를 정해야 합니다.
