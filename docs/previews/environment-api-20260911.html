시안에서 확인할 흐름

01. 서비스 선택 → 변수 이름 확인 → 키 입력 → 저장. 일반 환경변수는 저장할 파일을 선택합니다.
02. 터미널에서 이름 또는 값을 선택 → 우클릭 → 넣을 필드 선택 → 나머지만 입력 → 저장. 같은 이름이 있으면 덮어쓸 대상을 표시합니다.
