# GUI Stack 0.36 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** #142와 #153을 호환 가능한 GUI 이관 PR 하나로 대체한다.

**Architecture:** GUI crate를 같은 egui minor로 고정하고 App/Terminal 경계에서 변경된 API만 이관한다. 기존 winit IME patch와 Markdown broker 보안 경계를 유지한다. 독립 worktree에서 앱 --bin 테스트만 실행해 제품 앱을 재빌드하지 않는다.

**Tech Stack:** Rust 1.96.1, eframe/egui/extras/kittest 0.36, egui_commonmark 0.25, winit 0.30.13.

---

  `egui_extras = { version = "0.36", ... }`, `egui_kittest = "0.36"`,
  `egui_commonmark = { version = "=0.25", ... }`로 바꾼다. feature는 유지한다.
- [ ] `CARGO_BUILD_JOBS=2 cargo check -p terminal --tests`를 실행해 새 IMEOutput 필드의

- [ ] 기존 IME output 테스트에 `assert_eq!(ime.purpose, egui::IMEPurpose::Terminal);`
  검사를 추가한다. 새 필드를 일단 `purpose: egui::IMEPurpose::Normal,`로 연결하고
  `CARGO_BUILD_JOBS=2 cargo test -p terminal --lib --locked ime`에서 실제 assertion RED를 확인한다.

- [ ] `cargo tree -i winit`로 vendored 0.30.13이 유지되는지 확인하고 backport 문서의 eframe 버전을 갱신한다.
