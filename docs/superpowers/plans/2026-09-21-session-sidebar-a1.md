# 세션 목록 A1 적용 계획

**Goal:** 사용자가 승인한 A1 시안을 기존 두 줄 세션 행에 적용한다.

**Architecture:** WorkspaceUi의 기존 pane 제목 판별로 사용자 이름 여부와 Agent 모델/초기 제목을 목록 projection에 전달한다. FileTreeUi는 이름 또는 현재 작업을 첫 줄에, 상태를 둘째 줄 앞에 배치한다. 기존 runtime/storage/상태 판정은 유지한다.

**Tech Stack:** Rust, egui, 기존 i18n Catalog.

- [x] `crates/app/src/ui/workspace.rs`: 사용자 지정 이름 여부와 축약 모델을 session_entries에 전달한다. 작업 정보가 없는 Agent는 기존 프로젝트/상태 폴백을 유지한다. 기존 제목 저장/자동 작업 요약은 유지한다.
- [x] `crates/app/src/ui/file_tree.rs`: live/warm 공통 행에 필드를 전달하고 A1의 두 줄을 그린다. 이름 지정 시 둘째 줄에 상태·현재 작업·축약 모델, 미지정 시 상태·Agent·모델·강도를 표시한다. 이름을 비워 확정하면 기존 기본 제목 형식으로 복귀한다.
- [x] 리뷰에서 오표시로 확인된 초기 제목 분기와 `sidebar.session.new` 키를 다섯 로케일에서 제거한다.
- [x] 해당 변경만 직접 리뷰한다. 행 높이/간격/배경/드래그/포커스는 유지하고 좁은 폭은 말줄임과 clip으로 제한한다. 전체 정보는 hover에서 확인한다.
- [x] `docs/CODEX_HANDOFF.md`에 변경 및 검증 상태를 기록한다.

사용자 지시와 CLAUDE.md에 따라 UI 회귀 테스트/커밋 gate를 이번 단계에서 추가 실행하지 않는다. 사용자 요청 전 앱 재빌드/재실행도 하지 않는다. 실제 화면 확인은 이후 명시적 재빌드/재실행 요청 때 수행하며, 현재 완료로 주장하지 않는다. 이전 dirty 작업은 보존하고 자동 커밋하지 않는다.

## 리뷰 보완 (사용자 승인)

- [x] 이름 편집 상태/입력창 ID를 전체 세션 target으로 묶는다.
- [x] 보이는 입력창 소유의 키만 확정/취소에 사용하고 숨김/전환/종료 시 편집을 정리한다.
- [x] 새 세션 오판 분기를 제거하고 작업 정보 미확인은 기존 프로젝트/상태 폴백으로 표시한다.
- [x] 직접 코드 검토와 포맷 확인 후 인계를 갱신한다. 앱 빌드/재실행/실제 화면 확인은 요청 때까지 보류한다.
