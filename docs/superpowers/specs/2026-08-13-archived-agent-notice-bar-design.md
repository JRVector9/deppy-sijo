# 중단된 에이전트 안내 바 디자인

날짜: 2026-08-13

## 문제

앱 재시작 뒤 열람 전용으로 복원된 에이전트 pane은 터미널 최하단에 안내문과 실행 버튼을 투명 오버레이로 그린다. 안내 행 뒤로 마지막 터미널 출력과 커서가 비쳐, 안내문이 겹쳐 보이고 읽기 어렵다.

## 목표

중단 안내를 터미널 출력과 겹치지 않는 불투명 하단 바로 분리한다. 이어 실행 가능 여부, 버튼 활성화 조건, 버튼 클릭 동작, 다국어 문구는 그대로 유지한다.

## 확정 디자인

- 안내 바는 pane의 터미널 표면 최하단 전체 폭을 사용한다.
- 일반 높이는 `36pt`다.
- 배경은 불투명 중립 차콜 `#1A1D23`이다.
- 상단에 `1pt` 구분선 `#353B45`를 그린다.
- 안내문은 좌측 `14pt` 여백에서 시작하며 `14pt`, `#B0B5BF`로 한 줄만 표시한다.
- 버튼과 안내문 사이는 `12pt`, 우측 여백은 `12pt`다.
- 버튼은 높이 `26pt`, 배경 `#292E37`, 테두리 `#48505D`, 모서리 반경 `4pt`를 사용한다.
- 번역문이 길거나 pane 폭이 좁으면 안내문을 먼저 말줄임한다. 버튼은 클릭 가능한 크기와 전체 레이블을 우선 보존한다.
- 안내 바가 표시되는 동안 터미널 렌더 영역과 PTY 행 계산에서 바 높이를 제외한다. 따라서 터미널 출력·커서·선택·검색·드롭 표시는 안내 바 뒤에 그려지지 않는다.
- 비정상적으로 낮은 pane에서는 유효하지 않은 사각형을 만들지 않도록 바 높이와 터미널 영역을 가용 높이에 맞춰 제한한다.

## 상태와 동작

기존 `ArchivedResumePresentation` 매핑을 변경하지 않는다.

- `Exact`: `앱 종료로 중단됨` + `이어서 실행`, 활성
- `RecentInCwd`: `이 폴더의 최근 작업을 이어서 실행합니다.` + `이어서 실행`, 활성
- `Unsupported`: `이어 실행을 지원하지 않습니다.` + `새로 실행`, 활성
- `Unavailable`: `에이전트를 찾을 수 없습니다.` + `새로 실행`, 비활성
- `Checking`: `에이전트 설치를 확인하는 중…` + `새로 실행`, 비활성
- cross-workspace 첨부 pane에서는 현재처럼 버튼을 비활성화한다.

일반 셸이나 실제로 종료된 비복원 pane의 기존 `[종료: exit code …]` 표시는 변경하지 않는다.

## 구현 경계

변경 대상은 `crates/app/src/ui/workspace.rs`의 복원 에이전트 종료 안내 레이아웃과 렌더링이다. 새 설정, 저장 형식, 런타임 명령, 번역 키, 에이전트 이어 실행 전략은 추가하거나 변경하지 않는다.

레이아웃 계산은 순수 helper로 분리해 다음을 검증할 수 있게 한다.

1. 일반 pane에서 안내 바 높이와 색상 사양이 유지된다.
2. 터미널 content의 하단이 안내 바 상단을 침범하지 않는다.
3. 좁거나 낮은 pane에서도 사각형이 뒤집히지 않는다.
4. 기존 다섯 resume 상태의 문구, 활성화 여부, dispatch 동작이 유지된다.
5. 일반 종료 표시는 전용 안내 바를 예약하지 않는다.

## 검증

- 순수 레이아웃 테스트로 터미널 content와 안내 바가 겹치지 않는지 확인한다.
- egui kittest로 다섯 resume 상태의 레이블·버튼 활성화·클릭 dispatch를 확인한다.
- WorkspaceUi 집중 테스트와 `cargo check`, rustfmt, `git diff --check`를 실행한다.
- 사용자가 요청하기 전에는 앱을 다시 빌드하거나 실행하지 않는다.

## 비목표

- 안내 문구 변경
- 이어 실행 지원 범위 변경
- 버튼 동작 또는 자동 resume 정책 변경
- 일반 종료 메시지의 시각 재설계
- 터미널 전체 색상 체계 변경
