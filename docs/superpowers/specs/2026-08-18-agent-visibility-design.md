# 안 쓰는 에이전트 숨기기 설계

날짜: 2026-08-18
상태: 사용자 요청 접수, 설계
브랜치: `feat/agent-visibility` (워크트리 `/Users/jr/Desktop/projects/deppy-agentvis`, `main` 기준)
참조: stablyai/orca (`GlobalSettings.disabledTuiAgents`, `AgentsPane.tsx`)

## 문제

사용자 보고: **kimi 구독이 끝났는데 에이전트 목록에도 뜨고 하단 사용량 바에도 뜬다.**

실측한 원인 — 두 표면 모두 **「설치됐나」만 보고 「쓰고 있나」는 보지 않는다**:

| 표면 | 근거 | 코드 |
| --- | --- | --- |
| 에이전트 목록 | `AgentKind::ALL` 중 실행 파일이 PATH에 있는 것 | `agent_launcher::detect_installed_agents` |
| 하단 사용량 바 | kimi 설치 여부로 스스로 판정 | `kimi_usage::current`, `app.rs`의 `top_provider_usage` |

CLI를 지우지 않는 한 계속 뜬다. 구독이 끝났거나 그냥 안 쓰기로 한 에이전트를 치울 방법이 없다.

## orca는 어떻게 하나

**탐지와 표시를 분리한다.**

- `GlobalSettings.disabledTuiAgents: string[]` — 사용자가 제어하는 **거부 목록**
- 설정 → Agents 창에 에이전트별 켜기/끄기 토글
- 끈 에이전트가 `defaultTuiAgent`였으면 그 기본값도 **함께 해제**한다
- 탐지는 "그 호스트가 띄울 수 있는 것"을 계속 나열하고, 켜기/끄기·기본값은 그 위에 얹는
  **클라이언트 설정**이다

자동 판단(예: "N일 안 썼으니 숨김")은 하지 않는다 — 예측 가능성이 우선이다. 우리도 같은
선택을 한다.

## 범위

**넣는 것**

- `AgentsConfig`에 거부 목록 하나.
- **런처 카드에 상시 토글 스위치**(사용자 결정 2026-08-18, B안) — 문제를 보는 자리에서 바로
  끈다. 설정 화면까지 들어가지 않는다.
- 꺼지면 걸리는 표면 **둘**: 런처에서 **고를 수 없음**, 하단 사용량 바에서 **그 칸이 사라짐**.

**넣지 않는 것 (중요)**

숨김은 **"나에게 권하지 마라"**일 뿐, 지우거나 막는 것이 아니다. 다음은 **그대로 동작한다**:

- 이미 떠 있는 그 에이전트 세션 — 종료되지 않는다
- 그 에이전트로 만든 **작업 이력·원문 보기** — 과거 기록은 숨김과 무관하다
- 터미널에서 직접 `kimi`를 실행하는 것 — 우리가 막을 일이 아니다
- 상태 감지(`agent_detect`) — 떠 있는 세션의 상태는 계속 읽는다

이 경계를 지키지 않으면 "숨겼더니 이력이 사라졌다"가 된다.

## 데이터 모델

```rust
// crates/app/src/config.rs — AgentsConfig 안
/// 사용자가 목록·사용량 바에서 치운 에이전트 id("claude"|"codex"|"kimi").
/// 탐지 결과가 아니라 **취향**이다 — 설치돼 있어도 여기 있으면 권하지 않는다.
/// 미지 id는 로드 시 버린다(이전/이후 버전 config 호환, 기존 shortcuts 관례와 같다).
#[serde(default)]
pub disabled: Vec<String>,
```

상한: 항목 수는 `AgentKind::ALL` 수를 넘지 않게 로드 시 중복 제거·정규화한다.

## 동작

1. **에이전트 목록**: `detect_installed_agents`의 결과에서 거부 목록에 든 kind를 뺀다.
   탐지 자체는 그대로 둔다(설정 화면이 "설치됨 · 숨김" 상태를 보여줘야 하므로).
2. **사용량 바**: 거부 목록에 kimi가 있으면 `kimi_usage`를 `None`으로 만들어 칸 자체를
   그리지 않는다(이미 `None`이면 안 그리는 구조다). claude·codex도 같은 규칙을 적용해
   나중에 같은 요청이 와도 코드가 준비돼 있게 한다.
3. **런처 카드 토글 (B안)**: 카드마다 작은 스위치를 **항상** 보여준다.
   - **켜짐** — 지금과 같다. 고를 수 있고 띄울 수 있다.
   - **꺼짐** — 카드가 목록에 **남아 있되 흐려지고(muted), 고를 수 없다.** 자리를 차지하는
     대신 되돌리는 길이 같은 화면에 있다 — 이게 B안을 고른 이유다(설정을 찾아 들어가지
     않아도 된다).
   - 카드 본문 클릭은 꺼진 카드에서 아무 일도 하지 않는다. **스위치만** 반응한다.
   - 색은 `designall::tokens`에서 고른다(하드코딩 금지, 라이트/다크 둘 다).
4. **선택 비우기**: 켜져 있던 에이전트를 끄는 순간 그게 현재 선택이면 **선택을 비운다**.
   고른 적 없는 것이 골라져 있으면 다음 실행이 엉뚱해진다(orca가 `defaultTuiAgent`를
   해제하는 것과 같은 이유).
5. **마지막 하나**: 전부 꺼도 막지 않는다. 카드는 그대로 보이므로 빈 목록이 되지 않고,
   되돌리는 길도 그대로 남는다 — B안이 이 문제를 자연히 없앤다.
6. **사용량 바**: 꺼진 에이전트의 칸을 **그리지 않는다**(사용자 요청 2026-08-18).
   `kimi_usage`는 이미 `None`이면 칸을 안 그리는 구조라 그 경로를 그대로 쓴다. claude·codex도
   같은 규칙을 적용해 나중에 같은 요청이 와도 코드가 준비돼 있게 한다.

## i18n (5로케일)

`launcher.agent.enabled_hint`(스위치 hover, 켜짐), `launcher.agent.disabled_hint`(꺼짐),
`launcher.agent.disabled_badge`(꺼진 카드에 붙는 짧은 표시).

## 테스트

- 정규화: 미지 id 제거, 중복 제거, 빈 목록.
- 목록 필터: 거부된 kind가 빠지고 나머지는 순서 그대로.
- 사용량 바: 거부되면 그 칸이 안 그려지고, 남은 칸들의 배치가 깨지지 않는다.
- **경계 보장**: 숨겨도 이력 행·원문 보기·상태 감지가 그대로 동작한다는 계약을 테스트로 고정.
- 런처: 꺼진 카드는 **선택되지 않는다**(카드 본문 클릭이 무시된다), 스위치는 반응한다.
- 켜져 있던 현재 선택을 끄면 선택이 비워진다.
- 사용량 바: 꺼진 에이전트의 칸이 안 그려지고, 남은 칸들의 배치가 깨지지 않는다.
- 왕복: 토글 → config 저장 → 재로드 후에도 유지.

## 범위 밖

- 사용 빈도 기반 자동 숨김
- 에이전트별 세부 설정(모델·effort)과의 연동
- 설치 자체를 지우는 기능
