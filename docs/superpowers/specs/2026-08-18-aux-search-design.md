# 보조 본문 검색 (이력·Git) 설계

날짜: 2026-08-18
상태: 사용자 승인 완료 (범위: 좌측 목록 필터 + 우측 본문 강조·이동)
브랜치: `feat/work-history-depth`

## 문제

세션 헤더의 **검색 버튼**과 ⌘F는 터미널 스크롤백 검색을 연다. 그런데 이력·Git 보조 본문이
떠 있으면 그 pane은 입력 소유권이 없어(fail-closed) **눌러도 아무 일도 일어나지 않는다**.
보조 본문이야말로 긴 텍스트(대화 원문·diff·카드 목록)를 담고 있어 검색이 가장 필요하다.

## 범위

보조 본문이 **활성일 때** 검색 버튼과 ⌘F가 그 본문을 검색한다. 마스터-디테일 양쪽에 건다:

- **좌측 목록 필터** — 이력 카드(지시·요약·메시지 텍스트), Git 파일 행(경로)
- **우측 본문 강조 + ↑↓ 이동** — 원문 대화, diff 본문
- 검색 바는 보조 본문 **상단 전폭**. 입력 · `3/17` 카운터 · ↑↓ · ✕

보조 본문이 비활성(터미널을 보는 중)이면 **기존 터미널 검색 그대로**다 — 이 기능은 그 자리를
뺏지 않는다.

## 데이터 모델

App이 소유한다(leaf는 intent만 — 저장소 관례).

```rust
pub struct AuxSearchState {
    pub query: String,
    pub open: bool,
    /// 0-based. 일치가 없으면 무시된다.
    pub active: usize,
}
```

- 활성 보조 탭이 **바뀌면 닫고 비운다** — 이력에서 찾던 문구가 Git 목록을 걸러 놓으면
  "왜 안 보이지"가 된다.
- 워크스페이스 전환 시에도 비운다(`reset_git_surfaces`와 같은 자리).

## 매칭 규칙

- **대소문자 무시 부분 문자열**. 정규식은 범위 밖(입력 실수로 목록이 통째로 사라지는 것을
  피한다).
- 빈 질의는 "검색 안 함"과 같다 — 필터도 강조도 하지 않는다.
- **상한**: 본문당 일치 `MAX_AUX_MATCHES = 500`. 넘으면 잘림 표시만 하고 더 세지 않는다
  (거대 diff에서 매 프레임 전수 스캔하지 않기 위함).

## 좌측 목록 필터

- 이력 카드: `instruction` · `agent_summary` · `messages_json`의 텍스트에 하나라도 걸리면 남긴다.
- Git 파일 행: `rel_path`에 걸리면 남긴다. 워크트리 행은 **필터하지 않는다**(경로 목록이라
  검색 대상이 아니고, 통째로 사라지면 혼란스럽다).
- 걸린 게 없으면 목록 자리에 `search.no_match` 한 줄.

## 우측 본문 강조·이동

- 일치 구간을 `egui::text::LayoutJob` 섹션으로 나눠 배경만 다르게 칠한다. 색은
  `designall::tokens`에서 고른다(하드코딩 금지, 라이트/다크 둘 다 성립).
- **활성 일치**는 나머지와 다른 색으로 구분한다 — 그래야 ↑↓가 어디로 갔는지 보인다.
- ↑↓는 활성 일치를 앞뒤로 옮기고 그 위치로 스크롤한다. 양 끝에서 순환한다(마지막 다음은 처음).
- 카운터는 `{active}/{total}` 형식. 일치가 없으면 `0/0`.

## 진입

| 경로 | 동작 |
| --- | --- |
| 세션 헤더 검색 버튼 | 보조 본문 활성이면 보조 검색 토글, 아니면 기존 터미널 검색 |
| ⌘F (`A::TerminalSearch`, app.rs 단일 분기) | 같은 규칙 |
| Esc | 검색 바가 열려 있으면 닫는다 |

검색 바가 열리면 입력에 포커스를 준다. 보조 본문이 뜬 프레임은 터미널 입력 소유권이 없으므로
(fail-closed) 키 입력이 PTY로 새지 않는다 — 기존 계약을 그대로 쓴다.

## i18n (5로케일)

`search.placeholder`, `search.no_match`, `search.count`(`{active}/{total}`),
`search.prev`, `search.next`, `search.close`, `search.truncated`.

## 테스트

- 매칭·필터는 **순수 함수**로 뽑아 값으로 검증: 대소문자 무시, 빈 질의, 상한 초과, 유니코드
  (한글·이모지) 경계에서 자르지 않음.
- LayoutJob 섹션 분할: 일치 0·1·다중, 겹치지 않는 구간, 활성 일치만 다른 색.
- kittest: 검색 바 토글, ↑↓ 이동으로 활성 인덱스 변화, 필터 결과 행 수.
- 보조 본문이 비활성이면 검색 버튼이 **기존 터미널 검색**을 연다는 계약.

## 범위 밖

- 정규식·단어 단위·대소문자 구분 토글
- 검색어 이력, 저장
- 워크트리 행 필터
- 터미널 스크롤백 검색과의 통합(별개 UI로 둔다)
