# 환경 및 API 추가 흐름 · 검토용 시안

- 요청: 설정의 추가 화면과 터미널 선택 → 우클릭 → 환경변수 이름/값 채우기를 HTML로 먼저 보여준다.
- 범위: 독립 HTML 시안과 설계 기록. Rust 앱 구현, 저장 계약 변경, 재빌드·재실행은 포함하지 않는다.
- 기준: main `9432d33`, branch `design/environment-api-preview`.
- 시안: `docs/previews/environment-api-20260911.html`.

## 화면 구조

프로젝트와 폴더를 상단에 표시하고 전체/API 키/환경변수/환경파일로 나눈다. 목록에는 변수 이름, 표시 이름, 저장 위치, 값을 보여주며 비밀값은 마스킹한다.

API 추가는 서비스 선택 → 변수 이름 → 비밀값의 순서로 입력한다. 서비스 선택은 변수 이름의 기본값만 제안하며 인증 성공을 뜻하지 않는다. 일반 변수는 이름, 값, 저장할 파일을 고른다. 표시 이름은 선택 입력으로 접어둔다.

검토한 배치 대안:

1. **오른쪽 입력 패널(시안):** 기존 목록과 추가 내용을 함께 보며 터미널에서도 동일한 입력 흐름을 쓴다.
2. **중앙 모달:** 입력에 집중할 수 있지만 뒤의 목록과 터미널 선택 맥락을 가린다. 좁은 창에서는 시안 패널이 일부를 덮는 방식으로 대응한다.
3. **단계별 마법사:** 필드가 적은 흐름에 추가 이동을 요구하므로 이번 시안에서는 채택하지 않는다.

## 터미널 우클릭

선택 영역이 있는 pane의 워크스페이스를 대상으로 한다. 실제 구현에서 전체 화면의 선택 workspace 대신 원본 pane workspace ID를 캡처해야 한다.

- 이름으로 넣기: 이름을 채우고 값에 포커스한다.
- 값으로 넣기: 값을 채우고 이름에 포커스한다. 기존 변수도 선택할 수 있다.
- 이름과 값 함께 넣기: 단일 `NAME=value`일 때만 활성화한다. 셸 코드를 실행하지 않는다.
- 저장 전에는 반영하지 않는다. 같은 이름이면 대상 이름과 변경 안내를 표시하고 버튼을 `기존 값 바꾸기`로 바꾼다.

## 저장과 적용

API 비밀값은 안전한 저장소에, 일반 변수는 선택한 환경파일에 저장하는 기존 계약을 따른다. 실제 구현에서는 파일보다 API 연결이 우선하는 규칙과 출처 표시를 유지한다. 저장한 설정은 새 세션부터 사용한다. 실행 중인 Agent에 즉시 적용됐다고 표시하거나 자동으로 재시작하지 않는다.

시안은 브라우저 메모리의 예제 데이터만 편집한다. 실제 Keychain, 프로젝트 파일, Agent, 외부 API에는 접근하지 않으며 새로고침하면 초기화된다. 외부 라이브러리와 폰트 다운로드가 없는 단일 HTML이다.
