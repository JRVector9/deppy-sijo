# Command Center — 승인 화면 복원과 독립 작성

사용자의 2026-10-20 지시: 현재 앱을 승인 시안과 직접 비교하고, 모든 차이를 다시 목록화해 하나씩 수정한다. 메인 미연결 상태에서도 입력 가능하고 입력 영역에서 에이전트를 설정할 수 있어야 한다. 병렬 구현을 명시 승인했다. 화면 기준은 기존 `docs/mockups/multi-agent-command-center-v2-2026-10-20.html`의 최종 CSS와 렌더 구조다.

## 승인된 변경 범위

- 네이티브와 PWA 모두 승인 시안의 크기·색·정렬·정보 구조를 복원한다. 실제 데이터가 없는 화면을 가짜 작업·결과·기기로 채우지 않는다. OS 창 버튼, 실제 권한/상태 설명은 제품에 필요한 범위에서만 유지한다.
- 작성과 실행 권한을 분리한다. 프로젝트가 있으면 메인이 미연결이어도 초안을 작성·편집한다. 연결/승인/오프라인/저장 상태가 불확실하면 실제 전송은 기존 host guard가 판단한다.
- 입력 하단의 대상 표시는 설정 진입점이다. 기존 메인 세션 연결과 실제 사용 가능한 에이전트/모델/추론 강도 선택을 같은 입력 영역의 작은 팝오버에서 제공한다. 현재 메인이 없다는 이유로 입력부터 막지 않는다.
- 미연결 상태로 Enter/전송하면 작성 내용을 보존하고 에이전트 선택을 연다. 설정 저장/메인 연결·생성만으로 초안을 자동 전송하지 않는다. 설정이 확인된 후 사용자가 다시 명시 전송한다.
- 메인 연결 전후에도 같은 프로젝트의 메인 초안을 보존한다. 다른 프로젝트/작업/세션의 초안을 복사하거나 뒤섞지 않는다. 기존 원격 exact-owner·Relay read-only·중복 전송·IME/NFC·취소/실패 복구를 유지한다.
- 기본 화면에 내부 JSON·unbound·worktree 준비 절차를 크게 노출하지 않는다. 미연결은 ‘메인 에이전트 선택’처럼 사용자가 다음 행동을 이해할 수 있게 표시한다. 고급 수동 계획 기능은 접힘 영역에 남긴다.

## 검증 기준

현재 실제 앱의 AX/스크린샷을 먼저 관찰했다. 원본 시안과 같은 논리 viewport·theme·font에서 실제 egui 및 Chrome 렌더를 대조한다. 글꼴 확대를 상쇄하는 강제 축소, 작은 버튼, 영역별 중복 여백을 제거한다. 의미 있는 입력/연결/초안 보존 회귀는 실패를 확인한 뒤 수정한다. 작업별 근거 없이는 체크 완료로 표시하지 않는다.

현재 실행0.14.0의 교체는 이 수정 요청만으로 자동 실행하지 않는다. 앱 재시작은 AGENTS.md에 따라 해당 단계의 명시 요청이 있을 때만 수행한다. 현재 단계에서는 제품 소스와 격리 렌더·회귀 검증을 완료한다.
